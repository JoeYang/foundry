Project registry MCP for tracking my local Claude Code projects. Agents register and update; humans view in this dashboard.

Goal
Build a place where agents register the projects they're working on and upload structured updates (status, next step, decisions, todos, notes), so I can see them all in one dashboard and pick up where I left off after context switches.

Current decisions

+ new decision
  • Drizzle over Prisma
    Lighter, TS-first, better raw SQL escape hatch for pgvector. Prisma's pgvector support is still in preview.
    made 2h ago · by claude-opus-4-7 · confidence: high
  • HTTP/SSE for MCP transport (not stdio)
    Single daemon shares the pg connection pool with apps/api; multiple agents connect to one process instead of spawning per-session.
    made 2h ago · by claude-opus-4-7 · confidence: med · revisit_by: 2026-12-01
  • Path-as-identity for projects
    Agent always sends absolute path; server resolves to project_id. No caching, no .foundry/ hidden file. Self-correcting on directory move.
    made 2h ago · by claude-opus-4-7 · confidence: high
